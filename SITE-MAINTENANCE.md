# Подготовка и публикация сайта

Cloudflare Worker yellow-term-6761, домен vanyavtae.com. Канонические страницы без расширения .html; старые адреса перенаправляются правилами _redirects с кодом 301.

Перед публикацией выполняется `node prepare-site.mjs`. Этот шаг:

1. Формирует общие метаданные пяти страниц через site-meta.mjs / prepare-meta.mjs. Значения заголовков, описаний, canonical и картинок находятся в site-pages.json. При добавлении новой статьи добавьте её в этот файл.
2. Обновляет текстовый справочник партнёров в partners.html из places-data.js, между маркерами partner-directory:start и partner-directory:end. Не удаляйте маркеры. Интерактивные карточки и исходный HTML используют одинаковые данные.

## Версии CSS и JS (?v=)

Страницы подключают стили и скрипты с меткой версии, например `/places.js?v=phangan-20261023`. Когда метка меняется, браузеры посетителей скачивают файл заново, а не берут старую копию из кэша.

Все метки задаются в одном месте — таблице `ASSET_VERSIONS` в начале prepare-meta.mjs, по одной строке на файл. Файлы, которых нет в таблице, получают общую версию из page-polish.mjs (`20261022-2`).

Как менять:

1. Изменили, например, places.js — в `ASSET_VERSIONS` замените его метку на новую: `'places.js':'coffee-20261024'`. Формат: короткое слово о правке и дата ГГГГММДД.
2. Файла в таблице нет — добавьте для него строку.
3. Выполните `node prepare-site.mjs` и сохраните изменённые HTML вместе с правкой.

Не добавляйте новые строки `html.replace(...?v=...)` в конец prepare-meta.mjs: они перезаписывают друг друга, и итоговую версию становится трудно понять. Повторный запуск prepare-site.mjs не должен менять файлы — если меняет, это ошибка в скрипте.

- Наполнить Самуи (сейчас только Green Way) и дополнить Краби.
- Статья про аренду байка и депозиты.

Любимые места (кафе, пляжи, вьюпойнты) — компактные карточки: в places-data.js у записи spot:true, без логотипа, текст виден сразу, кнопка «На Google Картах». На Пхангане 12 таких мест со слов Вани (октябрь 2026); часть он посещал давно, поэтому во вступлении Пхангана просьба проверять места на Картах. Не упоминать печенье с коноплёй в The Dome Sauna. Фото с Google Карт не брать — только свои фото Вани. Каждый id нужно добавить в PARTNERS в click-worker.mjs.

Рекомендации: плашка (badge) ставится только для скидки или промокода — «Рекомендую лично» не используется, вся страница и так про личные рекомендации. Фильтры категорий показываются, только если у места 5 и больше карточек (places.js считает автоматически).

Правило дизайна: на сайте нет острых углов — карточки, блоки, картинки и кнопки скруглены. Картинки с текстом или скриншоты на карточках блога показываются целиком (класс story-card-graphic), а не обрезаются.

Основной дизайн сохраняется в styles.css, places.css и partners-cards.css. Дополнения аудита — site-fixes.css. Рекомендации в обычном HTML находятся в раскрываемом блоке «Все рекомендации и контакты», доступном и без скриптов; ссылки из него тоже имеют метки аналитики. Посетителям блок не показывается: places.js скрывает его, когда работают интерактивные карточки. Он остаётся в коде страницы для поисковиков и браузеров без JavaScript — не удаляйте его и не показывайте снова (решение Вани от 23 октября 2026). Строка «Подборка пополняется…» показывается только у мест без рекомендаций.

Кофе в partners.html: пять карточек с ассортиментом и ценами на 100, 150 и 200 г, переданными Ваней 23 октября 2026 года. Заказы принимает Рома: кнопка «Заказать кофе у Ромы в Telegram» открывает чат @RomaBlack с готовым черновиком «Привет, Рома! Я от Вани в Тае, хочу заказать кофе.» (решение Вани от 23 октября 2026); имя Рома в описании ведёт на Instagram @romablack. Фотографий пока нет. Не придумывать условия оплаты, стоимость доставки и наличие. Каталог хранится в обычном HTML и сохраняется при подготовке сайта.

Блок «Мои сервисы для поездок» (id="services") — обычный HTML в partners.html между справочником и кофе: Avosend, Trip.com, Booking, Agoda в этом порядке. Ссылки Avosend и Trip.com реферальные (rel="sponsored"), это прямо сказано в тексте блока; бонусы 450 ₽ и до 850 ₽ — со слов Вани, условия задают сервисы. Booking и Agoda пока без рефералок; российские карты они не принимают, Trip.com принимает карты РФ и СБП. Клики считаются с place="services". Пятая карточка — Т-Банк (реферальная ссылка на банк в целом, бонус зависит от выбранного продукта, указано «АО «ТБанк»»; логотип assets/logo-tbank.svg с Wikimedia Commons, public domain).

Под карточками мест — навигация «Ещё на этой странице» (.page-jump) с кнопками #services и #coffee; она заменила прежнюю строку «Ещё кое-что вкусное».

С главной ведёт ссылка /partners#services; places.js прокручивает к якорю, если это не остров.

Не смешивать предупреждения с рекомендуемыми сервисами. Общая плашка о мошенниках хранится в PLACE_SAFETY_NOTICE. Ссылка заказа кофе использует параметр text для черновика в Telegram; ничего не отправляется автоматически.

Логотип с цветной плашкой оставлен утверждённым: прозрачность для него не обязательна. Статьи про стоимость жизни, дым и Чиангмай готовятся отдельно с автором; технический аудит не добавляет вымышленных историй.

Cloudflare Web Analytics автоматически подключается Cloudflare к HTML. Клики партнёров собирает partner-clicks.js через click-worker.mjs в привязку CLICK_DB. Базу и конфигурацию wrangler.jsonc при правках контента сохранять. Изменение данных партнёров для новых контактов может потребовать обновления списка разрешённых событий в click-worker.mjs.

Не публиковать служебные файлы как статические ресурсы: правила находятся в .assetsignore. Репозиторий публичный — пароли и токены в нём запрещены.
