# Подготовка и публикация сайта

Cloudflare Worker yellow-term-6761, домен vanyavtae.com. Канонические страницы без расширения .html; старые адреса перенаправляются правилами _redirects с кодом 301.

Перед публикацией выполняется `node prepare-site.mjs`. Этот шаг:

1. Формирует общие метаданные пяти страниц через site-meta.mjs / prepare-meta.mjs. Значения заголовков, описаний, canonical и картинок находятся в site-pages.json. При добавлении новой статьи добавьте её в этот файл.
2. Обновляет текстовый справочник партнёров в partners.html из places-data.js, между маркерами partner-directory:start и partner-directory:end. Не удаляйте маркеры. Интерактивные карточки и исходный HTML используют одинаковые данные.

## Версии CSS и JS (?v=)

Страницы подключают стили и скрипты с меткой версии, например `/places.js?v=phangan-20261023`. Когда метка меняется, браузеры посетителей скачивают файл заново, а не берут старую копию из кэша.

Все метки задаются в одном месте — таблице `ASSET_VERSIONS` в начале prepare-meta.mjs, по одной строке на файл. Файлы, которых нет в таблице, получают общую версию из page-polish.mjs (`20261022-2`).

Как менять:

1. Изменили, например, places.js — в `ASSET_VERSIONS` замените его метку на новую: `'places.js':'coffee-20261024'`. Формат: короткое слово о правке и дата ГГГГММДД.
2. Файла в таблице нет — добавьте для него строку.
3. Выполните `node prepare-site.mjs` и сохраните изменённые HTML вместе с правкой.

Не добавляйте новые строки `html.replace(...?v=...)` в конец prepare-meta.mjs: они перезаписывают друг друга, и итоговую версию становится трудно понять. Повторный запуск prepare-site.mjs не должен менять файлы — если меняет, это ошибка в скрипте.

## Статьи: перелинковка и разметка

- В конце каждой статьи блок «Читайте также» (aside.read-also) с двумя другими статьями. Новую статью добавляйте в такие блоки вручную.
- Для статей в site-pages.json указывайте "type": "article" и "published": "ГГГГ-ММ-ДД" — site-meta.mjs добавит разметку Article для поисковиков (заголовок, автор, дата, картинка).
- У прокатов (Green Way, City Motorbike, Autain, Виктор · Samui One) есть кнопка «Как не потерять депозит» на /bike-rental-thailand, channel "article" — этот канал разрешён в click-worker.mjs.
