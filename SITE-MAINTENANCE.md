# Подготовка и публикация сайта

Cloudflare Worker yellow-term-6761, домен vanyavtae.com. Канонические страницы без расширения .html; старые адреса перенаправляются правилами _redirects с кодом 301.

Перед публикацией выполняется `node prepare-site.mjs`. Этот шаг:

1. Формирует общие метаданные пяти страниц через site-meta.mjs / prepare-meta.mjs. Значения заголовков, описаний, canonical и картинок находятся в site-pages.json. При добавлении новой статьи добавьте её в этот файл.
2. Обновляет текстовый справочник партнёров в partners.html из places-data.js, между маркерами partner-directory:start и partner-directory:end. Не удаляйте маркеры. Интерактивные карточки и исходный HTML используют одинаковые данные.

Основной дизайн сохраняется в styles.css, places.css и partners-cards.css. Дополнения аудита — site-fixes.css. Рекомендации в обычном HTML находятся в раскрываемом блоке «Все рекомендации и контакты», доступном и без скриптов; ссылки из него тоже имеют метки аналитики.

Кофе в partners.html: пять карточек с ассортиментом и ценами на 100, 150 и 200 г, переданными Ваней 23 октября 2026 года. Заказы через Telegram Вани; имя Рома ведёт на @romablack. Фотографий пока нет. Не придумывать условия оплаты, стоимость доставки и наличие. Каталог хранится в обычном HTML и сохраняется при подготовке сайта.

На Пхангане Autain Bike Repair — рекомендация; Nong cheap rent and repair bikes имеет status: 'not-recommended' и отображается отдельно, только как личный опыт Вани. Не смешивать предупреждения с рекомендуемыми сервисами. Общая плашка о мошенниках хранится в PLACE_SAFETY_NOTICE. Ссылка заказа кофе использует параметр text для черновика в Telegram; ничего не отправляется автоматически.

Логотип с цветной плашкой оставлен утверждённым: прозрачность для него не обязательна. Статьи про стоимость жизни, дым и Чиангмай готовятся отдельно с автором; технический аудит не добавляет вымышленных историй.

Cloudflare Web Analytics автоматически подключается Cloudflare к HTML. Клики партнёров собирает partner-clicks.js через click-worker.mjs в привязку CLICK_DB. Базу и конфигурацию wrangler.jsonc при правках контента сохранять. Изменение данных партнёров для новых контактов может потребовать обновления списка разрешённых событий в click-worker.mjs.

Не публиковать служебные файлы как статические ресурсы: правила находятся в .assetsignore. Репозиторий публичный — пароли и токены в нём запрещены.
