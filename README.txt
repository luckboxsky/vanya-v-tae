ОСНОВНЫЕ ИЗМЕНЕНИЯ В 2.6
1. «Две страны. Одна жизнь» и «Пожил на островах» объединены в одну главу
   01 / МОЯ ИСТОРИЯ. Пляжная фотография слева, утверждённый текст справа.
   Дублирующий блок удалён, после истории идёт «02 / Россия».
2. В шапке и подвале используется утверждённый логотип-картинка
   assets/logo-approved.png, вырезанный из предоставленного макета.
   Логотип не набран шрифтом заново. Обновлён favicon.
3. Фотографии людей отображаются в естественном соотношении сторон:
   головы и ноги не должны обрезаться. Подписи следуют за каждой фотографией.
4. Полоска слева охватывает оба абзаца пояснения перед карточками вопросов.
5. Пять платёжных методов помечены настоящими SVG-флагами/значком Bitcoin,
   а не буквенными обозначениями RU, TH, EU, KZ.
6. Подпись о поддержке: красное сердце, без точки в последней строке.
7. Остальные утверждённые формулировки из 2.5 сохранены без переписывания.

ПУБЛИКАЦИЯ
1. Загрузите этот ZIP как статический сайт в Cloudflare Workers / Static Assets,
   тем же способом, которым загружали предыдущие сборки.
2. Проверьте новую тестовую ссылку после публикации.
3. Реальные ссылки и реквизиты заполняются в config.js.
   Внимательно проверьте российский номер и банк перед публичным запуском.
   Некоторые контактные ссылки в текущей версии намеренно не заполнены:
   сайт показывает пояснения, а не переходит на выдуманные адреса.
4. Ни GitHub, ни серверные базы данных для размещения этой версии не нужны.
Сайт подключён к Cloudflare

Примечание: резервные фотографии автобуса на закате и зимнего случая
сохранены в assets/, но не вставлялись в новую сетку, чтобы не создавать
ещё один блок с неожиданными пустотами.
